El usuario está haciendo este proyecto de repaso para prepararse para su curso universitario de Programación Móvil. El proyecto CineLog cubre prácticamente todo el contenido del curso.

**Contenido del curso por semanas:**
- S1-2: Intro + setup (ya sabe esto)
- S3-4: Widgets, filas/columnas, navbar, alerts, bottomsheet
- S5: Gestión de eventos, controladores
- S6: Navegación con y sin parámetros (GoRouter)
- S8-9: Peticiones HTTP GET y POST
- S10: JWT + SharedPreferences
- S11: Persistencia local (base de datos local)
- S12: Cámara + REST
- S13: GPS + REST
- S14: WebSockets

**Why:** Quiere repasar todo antes de que empiece el curso para no ir perdido.
**How to apply:** Alinear el roadmap del proyecto con el contenido del curso. Priorizar lo que el curso evaluará: widgets, navegación, HTTP, JWT/SharedPreferences, y persistencia local.
